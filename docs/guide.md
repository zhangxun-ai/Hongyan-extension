# 安装与使用

[← 返回产品介绍](../README.md) · [官网教程](https://extensions.zhangxun.org/hongyan/guide/)

## 1. 获取并安装

在[官网联系区](https://extensions.zhangxun.org/hongyan/#wechat)扫码入群，私信作者获取安装包及对应浏览器的安装说明。后续版本可从 [Releases](https://github.com/zhangxun-ai/Hongyan-extension/releases) 获取。

按随包说明安装并启用红研，将插件固定到浏览器工具栏。安装或更新后刷新小红书页面，让页面使用新版本。

## 2. 免费体验与激活

首次启用后自动开始连续 2 小时免费体验，点击工具栏中的红研图标可查看剩余时间。关闭浏览器不会暂停计时。

永久授权首期价 ¥77，后续售价可能随版本迭代调整。联系作者获取授权码后，在红研弹窗或保存侧栏中输入并激活。首次激活需要联网，成功后永久使用；体验到期后已保存的资料保留。

## 3. 发现与选择笔记

- **首页**：浏览当前页面已加载的笔记，查看图文 Top10、视频 Top10 和 10W+ 榜单，勾选想保存的内容。
- **搜索页**：输入关键词，拓展关联词和长尾词，导出词表、词图或赛道分类；也可采集搜索结果中的笔记。
- **博主主页**：采集对标账号的笔记，整理这个账号的内容资料。
- **笔记详情页**：保存当前笔记资料，或采集评论。

同时启用点赞与评论筛选时，笔记需同时满足两项条件。互动指标缺失时不会当作 0；平台的“10万+”表示下限，不是精确统计值。

## 4. 导出与保存

| 保存方式 | 准备事项 | 适合用途 |
| --- | --- | --- |
| CSV 导出 | 无需连接资料库 | 用表格筛选、比较和整理笔记数据。 |
| 本地图文资料 | 无需连接资料库 | 阅读正文与图片，保留本地资料副本。 |
| 飞书多维表格 | 自己的多维表格 Base 链接和授权码 | 在多维表格中整理对标账号与笔记。 |
| Obsidian | 选择本地知识库目录 | 在知识库中积累账号、笔记与图片资料。 |

使用飞书或 Obsidian 时，先在“保存位置”完成连接，再勾选笔记并保存。已保存笔记可以继续补采评论。

## 常见问题

### 安装或更新后，页面没有变化怎么办？

先确认扩展管理页中的红研已启用，再刷新小红书页面。如果原页面提示连接失效，刷新后重新采集当前页面内容。

### 使用本地导出需要连接飞书或 Obsidian 吗？

不需要。两种资料库连接都是可选项。

### 首页榜单是不是全站榜单？

榜单来自当前页面已加载的笔记。浏览页面会带来新的样本，适合发现选题与挑选资料。

### 评论采集能拿到所有评论吗？

采集有数量、时间及展开范围限制，结果会说明范围。适合整理已取得的评论样本。

### 视频笔记会下载视频吗？

保存正文、图片链接和互动等笔记资料，不自动下载视频文件或转写语音。

### 为什么下载的关键词词图需要联网？

独立 HTML 词图打开时会加载可视化组件，需要联网。

### 体验到期后，已经保存的内容还在吗？

已保存的资料保留，可以继续阅读和整理。获取永久授权码后，在插件内激活即可继续使用功能。
