# 安装与使用

[← 返回产品介绍](../README.md) · [官网教程](https://extensions.zhangxun.org/hongyan/guide/)

## 1. 获取并安装

公开版仅提供 CRX 安装包。红研 26.10.16.12 已提交商店审核，正式发布并验证后开放下载；当前请查看[下载状态与安装说明](downloads.md)。开发源码必须获得授权并加入作者的 GitHub 私有仓库获取。

安装后将红研固定到浏览器工具栏，刷新小红书页面，让页面使用新版本。

## 2. 免费使用

插件免费使用。

视频转录是可选功能，需要自行配置第三方服务；第三方服务费用单独产生。

## 3. 发现与选择笔记

- **首页**：浏览当前页面已加载的笔记，查看图文 Top10、视频 Top10 和 10W+ 榜单，勾选想保存的内容。
- **搜索页**：输入关键词，拓展关联词和长尾词，导出词表、词图或赛道分类；也可采集搜索结果中的笔记。
- **博主主页**：采集对标账号的笔记，整理这个账号的内容资料。
- **笔记详情页**：保存当前笔记资料，或采集评论。

同时启用点赞与评论筛选时，笔记需同时满足两项条件。互动指标缺失时不会当作 0；平台的“10万+”表示下限，不是精确统计值。

## 4. 导出与保存

| 保存方式 | 准备事项 | 适合用途 |
| --- | --- | --- |
| CSV 导出 | 无需连接资料库 | 用表格筛选、比较和整理笔记数据。 |
| 本地图文资料 | 无需连接资料库 | 阅读正文与图片，保留本地资料副本。 |
| 飞书多维表格 | 自己的多维表格 Base 链接和授权码 | 在多维表格中整理对标账号与笔记。 |
| Obsidian | 选择本地知识库目录 | 在知识库中积累账号、笔记与图片资料。 |

使用飞书或 Obsidian 时，先在“保存位置”完成连接，再勾选笔记并保存。飞书首次使用建议通过插件帮助页下载并导入完整模板，包含笔记库、对标博主和原生博主分析，再填写这份 Base 的链接与授权码。Obsidian 选择知识库根目录后会自动准备红研目录、模板与资料视图，无需手动创建。已保存笔记可以继续补采评论。

## 常见问题

### 安装或更新后，页面没有变化怎么办？

先确认扩展管理页中的红研已启用，再刷新小红书页面。如果原页面提示连接失效，刷新后重新采集当前页面内容。

### 使用本地导出需要连接飞书或 Obsidian 吗？

不需要。两种资料库连接都是可选项。

### 首页榜单是不是全站榜单？

榜单来自当前页面已加载的笔记。浏览页面会带来新的样本，适合发现选题与挑选资料。

### 评论采集能拿到所有评论吗？

采集有数量、时间及展开范围限制，结果会说明范围。适合整理已取得的评论样本。

### 视频笔记会下载视频吗？

支持对可取得媒体地址的视频执行“下载视频”。逐字稿通过“获取逐字稿”单独发起，或明确开启“保存时获取逐字稿”；需要先配置转录服务。已有逐字稿可以复用，支持 TXT、Markdown 导出，SRT 需要有效时间信息。不是所有视频都能取得可下载或可转录的媒体地址。

### 为什么下载的关键词词图需要联网？

独立 HTML 词图打开时会加载可视化组件，需要联网。

### 为什么还看到试用或激活提示？

请在扩展管理页核对是否为免费版 `26.10.16.12`，再刷新小红书页面。旧版本或未刷新的页面可能仍显示原有提示。不要为此清除浏览器存储或删除已有资料。
