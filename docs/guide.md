# 使用教程

[← 返回产品介绍](../README.md) · [下载与安装](downloads.md)

> 本教程涵盖 `26.10.23.1` 开发版。当前公开包 `26.10.16.12` 不包含抖音适配、账号研究、内容解读与本地 Whisper；请先核对[版本范围](downloads.md)。

## 1. 安装与准备

按[安装说明](downloads.md)安装红研，固定到浏览器工具栏，并刷新已打开的平台页面。新版按小红书／抖音自动显示对应工作区。看到连接失效提示时，刷新页面后重新采集，无需清除存储。

本地导出不需要连接资料库。要保存到飞书或 Obsidian，先在红研的「保存位置」完成连接：

| 位置 | 操作 | 完成标志 |
| --- | --- | --- |
| 本地 | 选择「本地」，再选 CSV 或图文 HTML | 下载任务完成且文件可打开 |
| 飞书 | 按首次连接引导导入模板，填写自己的 Base 链接与授权码，完成必要检查 | 插件显示连接就绪，可打开自己的资料库 |
| Obsidian | 选择知识库目录并授权访问 | 插件显示已连接，保存后目录中出现 Markdown 和图片 |

飞书模板包含笔记库、对标博主等结构；新 Base 的原生分析仪表盘仍需按引导另行配置。Obsidian 按博主与作品整理资料，保护已有人工备注。浏览器再次请求目录授权时，选择原目录。

## 2. 发现、筛选与保存作品

| 页面 | 操作 |
| --- | --- |
| 首页 | 浏览平台推荐内容，在红研榜单中查看当前已加载作品并勾选 |
| 搜索页 | 先用平台搜索，再采集与筛选结果；按需拓展关键词；小红书可导出搜索赛道 |
| 博主主页 | 加载所需作品，按日期与类型筛选，选择资料或分析账号 |
| 详情页 | 直接下载／保存当前作品，按需获取逐字稿或解读内容 |

列表按「全部／图文／视频」、日期及互动筛选收窄。低粉高赞筛选可填写粉丝上限、点赞下限；必要指标未知时不会当作 0。更改筛选会移除不再匹配的已选项，切换类型页签可保留其他类型选择，注意底栏的总数与本页数量。

保存前选择目标和本地格式，核对底栏的输出条件。列表显示条件与保存／导出条件分别生效，已选数量不等于成功数量。输出条件同时启用点赞与评论时需同时满足。

飞书任务提交成功后，可换页或关闭来源页；从浏览器工具栏红研弹窗的「保存任务」查看进度、待确认事项和结果。此行为不适用于所有本地导出、Obsidian 或独立视频任务；这些任务按所在界面提示操作。

## 3. 拓展关键词与整理评论

**关键词**：在搜索页使用「关键词拓展」，完成后导出 CSV 或 HTML 词图。抖音使用平台原生搜索下拉联想，自动逐层拓展；运行时保持页面可见，避免操作原生搜索框，手动输入会停止任务并保留已取得结果。可主动停止；遇验证或平台限制时暂停，不连续重试。

抖音 HTML 导图可离线打开；小红书现有 HTML 词图需要联网加载可视化组件。联想词用于整理方向，不代表搜索量或需求强度。小红书搜索赛道通过独立入口导出，与关键词拓展分别使用。

**小红书评论**：在笔记详情采集与导出；已保存笔记可通过相应保存目标的评论补采入口继续处理。飞书在「补采评论」视图勾选，再从插件点击「补采飞书勾选项」；Obsidian／本地从保存结果进入「选择笔记补采评论」。仅在飞书勾选不会自动开始。

**抖音评论**：先在平台展开当前作品的评论，再点击「导出已加载评论」。仅导出本次页面已取得的样本。

## 4. 分析账号与对照作品（新版）

1. 在博主主页加载所需作品，点击「分析账号」。分析只使用当前账号的已加载样本，可按日期和类型查看表现。
2. 要对比账号，在同一浏览器窗口分别进入两个同平台博主主页并点击分析，再从研究窗口选择「对比账号」。
3. 要对照作品，在来源列表或研究页勾选 2—3 篇，点击「并排对照」，查看标题、封面、互动和正文；正文可展开阅读。

账号统计不套用低粉高赞条件，不代表历史全量或增长趋势。这里的统计与作品对照不调用 AI，不自动转录或保存资料。

## 5. 获取视频逐字稿

从视频详情点击「获取逐字稿」，或在保存资料时明确开启逐字稿。新版提供两种方式：

| 方式 | 配置 | 费用与限制 |
| --- | --- | --- |
| 本地 Whisper（新版） | 「设置 → 视频转录」下载本地助手，复制 AI 安装指引交给能执行本机命令的 Agent，安装并准备模型后回插件「检测连接」 | 使用本机算力；无需云端转录 Key，不自动改用云端。Apple Silicon Mac 已有实机验证，Windows／Linux／Intel Mac 仍需实机验证 |
| 豆包云端 | 在扩展安全设置页配置自己的服务 Key | 按服务商计费；新增转录先确认，已提交任务恢复时只查原任务 |

抖音详情可在原浮窗的「转录方式」中选择方式、检测本地助手并查看安装指引；云端 Key 在扩展安全设置页填写。

完成后选择 TXT、Markdown 或 SRT 下载，可多选；SRT 需要有效时间轴。已有逐字稿直接复用，无可用媒体、音轨或识别失败时不会制造文稿。保存资料时无法转录的视频会保留基础资料，按结果提示处理。

## 6. 解读单篇内容（新版）

1. 从红研设置进入「AI 内容解读」，填写自己的 DeepSeek API Key，保存并检测连接。
2. 打开小红书或抖音作品详情，点击「内容解读」。
3. 在原浮窗查看「核心内容、用户价值、表达方式」，查看「本次材料」，按需复制或下载 Markdown。

默认 Flash；Pro 仅分析文字。所用正文、逐字稿、图片／视频关键帧和已加载评论样本会按模型能力发送给 DeepSeek。解读不会主动抓全评论；缺逐字稿时沿用转录设置，新增云端转录另需确认。

已完成结果按作品与模型保留最新成功解读，重新打开直接复用。「重新解读」会再次请求模型并可能计费；失败保留上次成功结果。解读不会自动写入飞书或 Obsidian。AI 输出供研究参考，请结合原文判断。

## 常见问题

**找不到新版按钮？** 核对扩展管理页的版本。旧公开包没有新版功能；重载或更新扩展后还需刷新平台页面。

**下载是不是已经成功？** 以浏览器下载完成及实际文件为准；仅创建任务、出现保存框或显示处理中不代表完成。

**为什么选了多篇，实际保存较少？** 查看底栏输出条件与逐篇结果；不达标、指标未知或读取失败都可能影响数量。已选数量不承诺成功数量。

**能采全账号作品和评论吗？** 不保证。榜单、分析和评论都有明确样本范围，平台不可访问的内容无法补齐。

**密钥会不会出现在导出中？** 服务密钥保存在本机扩展中，不写入网页或导出；云端功能会将所需内容提交给对应服务商。反馈问题时请勿粘贴 Key、授权码、Cookie 或私人材料。

**如何降低账号风险？** 作者自测暂未遇到封控，不保证零风险。可先小号测试；出现平台提醒或异常时暂停并按平台提示处理。
