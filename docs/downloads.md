# 版本下载

[← 返回产品介绍](../README.md) · [查看 Releases](https://github.com/zhangxun-ai/Hongyan-extension/releases)

## 获取插件

当前请前往[官网联系区](https://extensions.zhangxun.org/hongyan/#wechat)扫码入群，私信作者获取安装包与对应浏览器的安装说明。

后续可公开下载的版本统一放在本仓库的 **Releases**。每个版本会列出版本号、更新内容、适用浏览器、安装方式和安装包，便于选择与回看历史版本。

## 如何选择下载文件

1. 打开 [Releases](https://github.com/zhangxun-ai/Hongyan-extension/releases)，选择最新正式版本。
2. 阅读该版本的安装说明，在 **Assets** 中选择说明指定的安装包。
3. 按对应浏览器的步骤安装或更新；更新后刷新小红书页面。

GitHub 自动生成的 **Source code (zip)** 和 **Source code (tar.gz)** 只包含本介绍仓库的文档与图片，不是红研插件安装包。

预览版本如标有 **Pre-release**，请先阅读该版本说明再决定使用。每次更新以具体版本的安装说明和变更记录为准。

## 更新提醒

可以在仓库右上角选择 **Watch → Custom → Releases**，订阅版本发布通知。

遇到安装或更新问题，请提供版本号、浏览器版本和操作步骤，使用[问题反馈表单](https://github.com/zhangxun-ai/Hongyan-extension/issues/new/choose)，或联系 [support@zhangxun.org](mailto:support@zhangxun.org)。
