## ZIP 安装

1. 下载并解压 ZIP，将解压后的文件夹放在一个会长期保留的位置。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。
4. 确认扩展已启用、版本为 `26.10.16.12`，将红研固定到工具栏，再刷新小红书页面。

ZIP 不能直接拖入当作已签名的 CRX 安装。开发者模式安装的扩展可能显示浏览器提示；无需修改浏览器安全策略。其他 Chromium 浏览器的入口名称可能不同，以其扩展管理页为准。

## 更新已有安装

已通过“加载已解压的扩展程序”安装的用户，先关闭正在运行的采集/保存任务，将新 ZIP 解压到原加载文件夹、覆盖同名运行文件，再在扩展管理页点击重新加载，最后刷新小红书页面。不要删除原扩展或清除浏览器存储。

从应用商店版改用 ZIP，或更换解压目录，可能产生不同扩展 ID，原配置不会自动迁移。请保留旧安装与已有资料，按需重新连接飞书/Obsidian；不要同时运行两份红研。相同扩展 ID 的免费升级保留本机设置与资料。

应用商店更新的审核、发布状态以商店页面为准，不把 ZIP 版本号视为商店已发布证明。
