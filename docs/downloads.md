## 当前下载状态

公开版只提供 CRX 安装包，不提供开发源码或解压版 ZIP。红研 **26.10.16.12** 已提交 Chrome 应用商店审核；正式发布并完成安装验证后，再开放官网和 GitHub 的同版本 CRX 下载。

- [官网下载说明](https://extensions.zhangxun.org/hongyan/guide/#download)
- [GitHub 发布页](https://github.com/zhangxun-ai/Hongyan-extension/releases)
- [Chrome 应用商店](https://chromewebstore.google.com/detail/pjdbnlfpofkgcglogmdgplamgabooceo)：新版尚未上架，安装前请核对实际版本。

## 安装与更新

新版正式上架后，推荐通过应用商店点击“添加至 Chrome”安装。CRX 下载开放后，可将 CRX 文件拖入浏览器扩展程序管理页并按提示添加，无需解压；如浏览器不允许离线安装，请使用商店，不要关闭安全保护。

更新时保留原扩展和本机资料，不清除存储。同一商店 ID 的更新由浏览器处理，不同 ID 的安装不保证自动继承配置。不要同时运行两份红研。

## 源码获取

本公开仓库仅提供产品文档、图片和正式 CRX 安装包，不包含开发源码。GitHub 自动生成的 Source code 归档仅是本介绍仓库的文档和图片，不是红研开发源码或插件安装包。

源码须[联系作者获得授权](https://extensions.zhangxun.org/hongyan/#wechat)，加入作者的 GitHub 私有仓库后获取；免费使用插件不包含商业源码授权。
